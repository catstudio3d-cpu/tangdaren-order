# 湯達人 QR Code 點餐系統

網站：https://catstudio3d-cpu.github.io/tangdaren-order/

前端由 GitHub Pages 發布，後端使用 Supabase 專案 knwxopwntkhmmijxrsps。

完整可建置原始碼：[source.zip](./source.zip)。本儲存庫不包含實際員工密碼、密碼雜湊、既有訂單或營收資料。

目前為菜單瀏覽模式，尚待私有登入設定完成後才開放點餐與員工後台。

GitHub Pages 發布來源：main 分支 /(root)。修改程式時請解壓縮 source.zip，在專案內執行 npm ci、npm run build、npm test，並更新根目錄 index.html、cloud.js、qr.js 與 source.zip。
